# Imitation-Assignment-2-

This repo contains a scaffold for the CSS3 image projects assignment.

Files added:

- `index.html` — the assignment page with six example projects and a fullscreen image viewer (keyboard accessible).
- `styles.css` — styles and CSS3 effects used for the six projects.

What you must do next

1. Create a folder named `images` at the repository root.
2. Download the assignment source images and add them to `images/` with these exact filenames:
	- `source1.jpg`
	- `source2.jpg`
	- `source3.jpg`
	- `source4.jpg`
	- `source5.jpg`
	- `football_field.jpg`
	- `tic-tac-toe.png`
3. Preview `index.html` in your browser (double-click or run `xdg-open index.html`).

When ready, commit the images and the HTML/CSS to GitHub and submit the repo URL to your teacher.

- commit and push these scaffold files for you now, or
- wait and refine the CSS once you upload the original images so it matches the target screenshots more closely.
